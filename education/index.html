Self-directed

The curriculum I set myself.

Four tracks, each with a public repository you can read end to end.

Quantum computing

Qiskit circuits for Shor's algorithm, Grover's search, phase estimation, teleportation, superdense coding and quantum machine-learning kernels.

Production machine learning

DVC pipelines, MLflow tracking, quality gates, retraining and rollback, learned by building the NDR and medical-imaging platforms end to end.

Transformers from first principles

A GPT-2 architecture and byte-level BPE tokenizer implemented in PyTorch without the transformers library, module by module with tests.

Security analytics

Network flow features, Zeek telemetry and rule-based detection built alongside a gradient-boosted classifier.
