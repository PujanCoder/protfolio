Retrieval mode, grounded in portfolio data

Ask about the engineering, not the adjectives.

Answers come from a curated knowledge base of published facts — metrics, stack, architecture decisions and limitations. If something is not published, the assistant says so instead of guessing.

Enter to send, Shift + Enter for a new line. Rate limited to 20 questions a minute.

Try one of these

How this works

  • Answers are retrieved from a curated knowledge base of published facts.
  • With an API key configured server-side, a model composes the answer from those facts.
  • Without a key the endpoint still answers, in retrieval mode, and says so.
  • No key ever reaches the browser: the request is server-side and rate limited per IP.
