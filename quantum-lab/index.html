Quantum computing lab

Quantum mechanics you can actually poke at.

An exact statevector simulator running in your browser: build a circuit, watch the reduced Bloch vector move, and read the Qiskit equivalent line by line. Every number below comes from the linear algebra, not from a screenshot.

The advocate programme is a community recognition from IBM Quantum. The public evidence here is the Qiskit work itself: every experiment below is a repository you can open and run.

How this lab computes

  • State is a complex vector of length 2ⁿ, evolved by exact 2×2 matrix multiplication.
  • The Bloch vector is the partial trace of the register, so entangled qubits correctly show a shortened arrow.
  • Measurement samples the Born probabilities. There is no noise model, so real hardware counts will differ.

Qiskit equivalent

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

circuit = QuantumCircuit(1, 1)
circuit.h(0)
circuit.measure(range(1), range(1))

result = AerSimulator().run(circuit, shots=1024).result()
print(result.get_counts())

Runs on the local Aer simulator. Nothing in this lab touches IBM hardware.

Two phenomena

Superposition and entanglement, measured

The two ideas that make quantum computing different, shown as statistics rather than adjectives.

Superposition

One gate, two outcomes, no preference

H maps |0⟩ to (|0⟩+|1⟩)/√2. The amplitudes are equal, so every shot is a coin flip with p = 0.5 — and the histogram only settles as the sample grows.

Entanglement

Two qubits, one shared outcome

The Bell pair (|00⟩+|11⟩)/√2 never produces 01 or 10. Each qubit alone looks like a fair coin, yet the pair is perfectly correlated.

Scope

What this lab is, and what it is not

Being explicit about the boundary is the difference between a demo and a claim.

What it is

  • An exact simulator for 1–3 qubits, including phase-accurate amplitudes.
  • A teaching surface for gates, circuits and measurement statistics.
  • Qiskit code that reproduces the same circuit on Aer.

What it is not

  • Not a run on IBM Quantum hardware, and not a noise or error-mitigation study.
  • Not a quantum advantage claim: 3 qubits is a classroom, not a benchmark.
  • Not a substitute for the notebooks, which run larger circuits on Aer and hardware.
